# Product

## Register

product

## Users

Newspack team members at Automattic (designers, developers, support) landing here to download or update Newspack Shots, a macOS menu-bar screenshot and screen-recording app. They arrive from Slack, P2 posts, or the README with one job: get the latest DMG installed, and occasionally look up a shortcut or an install/gatekeeper step. A secondary audience is AI agents and teammates evaluating the MCP server integration ("for humans and agents alike").

## Product Purpose

The site is the single download page for Newspack Shots releases (the app source is private; this repo hosts only downloads and this page). Success: a teammate finds the latest version, understands the unsigned-app install dance, and gets capturing in under a minute. The page also showcases what the app produces, so the styled shots on the page are proof of the product itself.

## Brand Personality

Playful, punchy, bold. The page serves a utilitarian job (download, install, learn shortcuts) but does it with energy: confident color from the Newspack palette, lively copy, and screenshots that show off. Personality lives in the details and never gets in the way of the download button.

## Anti-references

- Generic SaaS landing pages: hero-metric templates, identical feature-card grids, gradient text, stock illustration.
- Corporate/enterprise marketing: stiff, dense, jargon-heavy.
- Dev-tool brutalism: terminal-dark, monospace-everything, neon-on-black.

## Design Principles

- **The page is the demo.** Every screenshot and recording shown must be output from the app itself; the site proves the product works by wearing it.
- **Download first, delight second.** The primary task (get the DMG, follow the install steps) is never more than a glance away; playfulness decorates the path, never lengthens it.
- **Newspack blood.** Color, type, and tone come from the Newspack brand (Cobalt, Emerald, Inter); the page should feel unmistakably part of that family.
- **Punchy, not loud.** Bold moments are deliberate and few; the rest of the page stays crisp so those moments land.
- **Agents are users too.** Content stays parseable and precise (real version numbers, real shortcuts, real checksums), because AI agents read this page as much as humans do.

## Accessibility & Inclusion

WCAG AA contrast throughout. Honor `prefers-reduced-motion` for all animation. Keyboard-friendly navigation and visible focus states. Internal-team audience, but no formal exceptions: the page should work with screen readers and at 200% zoom.
