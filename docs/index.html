For humans and agents alike

Your agent captures through the same engine.

You press ⌃⇧2; your agent calls a tool. The results are pixel-identical.

Newspack Shots isn't just a screenshot app for people. It's also an MCP server, so the AI agents you work with take screenshots through the same styling engine you do, in any style you name. Docs, P2 posts, and help pages stay visually consistent no matter who, or what, captured them.

It comes with a skill: the team's screenshot playbook of canonical capture sizes, the website recipe, and how to annotate. The app installs it for Claude Code and Codex automatically and keeps it up to date.

Claude Code · agent session

The app hands your agent this toolbox, served as newspack-shots (the skill shares the name):

Capture

capture_fullscreen

Styled full-screen shot, saved and ready.

capture_window

A named app's window, true corners and shadow; 3:2 on request.

capture_region

An exact pixel region, 3:2 canvas by default.

capture_scrolling

Auto-scrolls a region and stitches it into one tall shot.

list_windows

What's capturable, so agents don't guess window names.

Style & compose

style_image

Brands any existing image, the way agents style website captures.

style_video

Brands workflow videos with title cards, captions, and click ripples.

compose_grid

Lays 2 to 12 shots into one styled masonry grid.

Annotate & verify

annotate_image

Arrows, rectangles, spotlights, counters, caption chips, pixelate.

read_text

OCR a screen region to read dialogs and errors. Nothing saved.

video_frames

Extracts stills from a recording so agents can verify what it shows.

No setup: the app installs the skill and registers the MCP server for Claude Code and Codex on first launch. Installed an agent later? Open the app's Settings once and it wires itself up. Toggle it in Settings → General. See the README for details.

Install in a minute

Five steps, one of them Apple's fault.

The app is unsigned (no Apple Developer Program), so macOS asks once. After that it's plain sailing.

Newspack Shots.dmg
  1. Download the DMG and drag Newspack Shots onto Applications.
  2. macOS blocks the unsigned app once: double-click it, click Done, then allow it under System Settings → Privacy & Security → Open Anyway.
  3. Trigger your first capture and grant Screen Recording, then quit and relaunch the app once.
  4. Working with AI agents? Nothing to do: the app registers the MCP server and installs the team skill for Claude Code and Codex automatically (opt out in Settings → General).
  5. That's it. Captures land styled, saved, and on your clipboard.

Screenshots and recordings never leave your Mac. No cloud, no upload, no analytics.
