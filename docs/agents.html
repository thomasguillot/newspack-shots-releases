Newspack Shots for AI agents

No Mac? An agent can still produce on-brand captures: shoot the website to spec in its own browser, then style stills and grids with a module served from this site. The full recipe lives in one markdown file made to be fetched:

https://thomasguillot.github.io/newspack-shots-releases/agents.md

Point your agent at that URL. It covers the capture spec (viewport, pixel density, cleanup CSS), the styling calls, and grid composition.

Window captures, screen recordings, styled video and annotations still need the app on a capable Mac.
